# How the book teaches

Readers are MBA students from non-technical backgrounds preparing for placement interviews. They are smart, short of time, and anxious. The book has to make them able to *reason* about AI in a case or GD, not recite definitions.

## Principles, and where each shows up

| Principle | Evidence base | In the book |
|---|---|---|
| Activate prior knowledge before new ideas | Ausubel's advance organisers | Every chapter opens from something familiar (cricket par score, delivery ETA) before any jargon. |
| Build from first principles | Worked derivation beats stated rules for transfer | `principle` blocks: obvious premises → steps → ∴ conclusion. |
| Concrete before abstract | Concreteness fading | Napkin-scale example first (2 parameters), then scale up (billions). |
| Worked examples reduce cognitive load | Sweller, cognitive load theory | `case` blocks are worked end to end before readers try alone. |
| Dual coding | Paivio | One figure per major idea; the cover itself is a real mechanism. |
| Retrieval practice beats rereading | Roediger & Karpicke | `check` blocks with answers hidden (upside down in print). |
| Elaboration and transfer | Bloom's taxonomy | Questions tagged recall → apply → explain → transfer → judge. Objectives use Bloom verbs. |
| Address misconceptions explicitly | Conceptual change research | `concept` cards name the misconception; `myth` blocks refute one each. |
| Active learning | | `try` blocks: the reader runs a prompt and sees the concept happen. |
| Signalling | Mayer's multimedia principles | Highlighter = the one sentence that matters. Skim layer + recap = the night-before read. |
| Interleaving across contexts | | `lens` blocks show the same idea in consulting, marketing, ops, product... |

## The chapter arc

1. **Opener**: number, title, deck, read/skim time, lenses, *the puzzle* (a concrete question), 3–4 objectives.
2. **Lede**: start from the familiar. First highlighted sentence = the chapter's thesis.
3. **From first principles**: derive the core idea.
4. **Name it**: concept cards for the 1–3 terms that matter. Glossary terms in the rail.
5. **Scale it / complicate it**: where the simple model breaks, with a figure.
6. **Evidence**: a stat or study, cited. A myth block if a misconception is common.
7. **Worked case**: a business decision, end to end.
8. **Lenses**: 2–4 tracks, a few sentences each.
9. **Interview room**: one realistic question with the structure of a strong answer.
10. **Try it yourself**: one prompt.
11. **Watch / Read**: 1–3 sources, each with *why* and what to skip.
12. **Check yourself** + answers: 4–6 questions across Bloom levels.
13. **The night-before page**: five lines.

## Density targets

- 2,000–3,500 words a chapter (10–16 minutes of full reading).
- One highlight per section, 4–8 per chapter. If everything is highlighted, nothing is.
- Every paragraph earns its place: if a student could skip it and lose nothing in an interview, cut it.
